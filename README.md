Project Description
This project is a simple Hospital Management System developed using Java. It manages patient information and calculates hospital bills using Object-Oriented Programming (OOP).
Classes Used
1. Patient
Stores the patient's name.
Stores the consultation fee (consultFee).
Contains a constructor to initialize patient information.
Uses the displayInfo() method to display patient details.
2. InputPatient
Extends the Patient class.
Stores room information, room charges, and the number of days.
Calculates the patient's room charges.
3. OutputPatient
Extends the patient class
